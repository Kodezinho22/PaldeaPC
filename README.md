# PaldeaPC

Launcher e runtime para Windows, com gerenciamento de jogadores, sistema de atualizações e cooperativo experimental.

## Versão atual

**PaldeaPC v0.1.3 Beta - M18.6 completa / Caminho B**

Instalação completa validada pela internet pública, com launcher, runtime, dependências e Pokémon Violet com a atualização 4.0.0. O projeto continua em desenvolvimento.

## Cooperativo

O modo cooperativo via Radmin VPN está em fase experimental. Os testes entre computadores diferentes serão realizados com os participantes da Beta.

## Downloads

[Baixar PaldeaPC-Setup.exe](https://github.com/Kodezinho22/PaldeaPC/releases/download/v0.1.3-beta/PaldeaPC-Setup.exe) · [Notas e arquivos da versão](https://github.com/Kodezinho22/PaldeaPC/releases/tag/v0.1.3-beta)

Baixe somente o instalador de 701.440 bytes. Ele baixa as seis partes do pacote completo (aproximadamente 9,31 GiB), verifica sua integridade e instala o conteúdo automaticamente, sem importação ou extração manual.

O instalador antigo M18.8 não reconhece o manifesto schema 3 desta versão. Se você já possui esse EXE, baixe novamente o instalador pelo link acima (M18.9 Caminho B).
