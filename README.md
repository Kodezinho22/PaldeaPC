# PaldeaPC

Launcher e runtime para Windows, com gerenciamento de jogadores, sistema de atualizações e cooperativo experimental.

## Versão atual

**PaldeaPC v0.1.2 Beta**

Projeto em desenvolvimento, com testes de instalação, atualização e recuperação de versões.

## Cooperativo

O modo cooperativo via Radmin VPN está em fase experimental. Os testes entre computadores diferentes serão realizados com os participantes da Beta.

## Downloads

As versões e os arquivos disponíveis serão organizados na seção **Releases** deste repositório.
